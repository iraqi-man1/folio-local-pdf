> **حالة المشروع:** أدوات المرحلتين 1 و2 منفّذة. نجحت اختبارات الخدمة والبناء، وفُحصت بعض المسارات داخل المتصفح. ما زال فحص ملفات ممثّلة كبيرة ومصوّرة وعربية ومحمية، وبعض خطوات الواجهة، جارياً. الأدوات المخططة تظهر في الفهرس مع رقم مرحلتها ولا يمكن تشغيلها بعد.

## التشغيل

تحتاج Node.js واتصالاً بالإنترنت **وقت تثبيت الحزم فقط**. من مجلد المشروع:

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

افتح العنوان الذي يعرضه Vite، عادةً `http://127.0.0.1:5173/`.

لإنشاء نسخة ثابتة تعمل محلياً بدون Node أو إنترنت بعد البناء:

```powershell
npm run build
npm run preview -- --host 127.0.0.1
```

يمكن أيضاً نسخ **محتويات** `dist` إلى `C:\xampp\htdocs\localpdf\` وفتح `http://localhost/localpdf/`. يقدّم Apache الملفات الثابتة فقط؛ معالجة المستندات تحصل داخل المتصفح. استخدم Chrome أو Edge حديثاً إذا أردت الحفظ المباشر إلى مجلد تختاره؛ في بقية المتصفحات يُنزّل الملف عبر مجلد التنزيلات.

## الأدوات المتاحة

| المجال | ما يمكن عمله الآن |
| --- | --- |
| العرض والتنظيم | عرض PDF، شبكة مصغّرات لكل الصفحات، معاينة كبيرة، ترتيب بالسحب، انتقال برقم الصفحة، تدوير، نسخ، حذف واستخراج |
| الدمج والتقسيم | دمج ملفات متعددة بالترتيب، تقسيم بنطاقات أو كل صفحة أو كل عدد محدد أو الصفحات الفردية والزوجية |
| الصور | JPG/JPEG إلى PDF مع حجم الصفحة والهوامش؛ صفحات PDF إلى JPG داخل ZIP بدقة 72–600 DPI |
| الضغط | ضغط بلا فقدان يحافظ على النص والروابط؛ خيار أصغر للملفات المصوّرة يحوّل الصفحات إلى JPEG بدقة 120 DPI |
| التعليقات والأمان | علامات مائية نصية أو صورية، ترقيم صفحات، قص حدود العرض، حماية AES-256، فتح بكلمة المرور الصحيحة، تعديل البيانات الوصفية وتنظيفها |
| الاستخدام | سحب وإفلات، اختيار ملفات أو مجلد، لصق من الحافظة، واجهة عربية/إنجليزية، وضع فاتح/داكن، اسم ومجلد للناتج |

الملف الأصلي لا يتغير افتراضياً؛ يُحفظ الناتج في ملف منفصل. إذا أنتج الضغط ملفاً أكبر، يحتفظ التطبيق بحجم الملف الأصلي. خيار الضغط المصوّر **يفقد النص القابل للتحديد والروابط والنماذج والتفاصيل المتجهة**؛ اختر الضغط بلا فقدان إذا احتجت هذه العناصر.

## الخصوصية

- تُفتح الملفات وتُعالج داخل المتصفح على جهازك؛ لا توجد واجهة رفع، حسابات، تتبع أو خدمة معالجة سحابية.
- ملفات PDF.js وqpdf WASM والخطوط اللازمة للتشغيل مضمنة محلياً في البناء.
- قائمة «الأخيرة» تحفظ أسماء الملفات ونوع العملية والتاريخ وعدد الصفحات فقط، ولا تحفظ محتوى المستند.
- الصور عالية الدقة والملفات الكبيرة تستهلك ذاكرة المتصفح، وقد تتجاوز حدود الجهاز.

## حدود مهمة

- فتح ملف محمي في العارض العادي يعرض رسالة؛ استخدم أداة فتح الحماية وأدخل كلمة المرور الصحيحة.
- القص يغيّر الجزء الظاهر من الصفحة، لكنه لا يمحو المحتوى المخفي؛ الحجب الدائم للمعلومات أداة مخططة لاحقاً.
- الإصلاح يعيد كتابة البنية التي يمكن استردادها، ولا يعيد محتوى صفحة مفقوداً.
- تنظيف البيانات الوصفية يغطي حقول Info وXMP الرئيسية، وليس كل البيانات الشخصية داخل الصفحات أو المرفقات.

## التحقق

```powershell
npm test
npm run lint
npm run build
```

اجتازت اختبارات الخدمة الـ19 واختبارات البناء. فُحصت محلياً بعض وظائف القص والمعاينة والترقيم والضغط والتنقل وRTL والوضع الليلي. شبكة التنظيم وخيار الضغط المصوّر يحتاجان فحصاً تفاعلياً إضافياً مع الناتج المُنزّل؛ كذلك يبقى فحص ملفات كبيرة ومصوّرة وتالفة ومحمية، والحفظ المباشر وXAMPP، مفتوحاً. راجع [بحث المرحلة 1](docs/phase-1-research.md) و[بحث المرحلة 2](docs/phase-2-research.md) للتفاصيل.

## بنية المشروع

| المسار | المسؤولية |
| --- | --- |
| `src/App.tsx` و`src/App.css` | الواجهة ومسارات العمل |
| `src/lib/pdf-service.ts` | العرض وتجميع الصفحات والتحويل إلى صور |
| `src/lib/qpdf-service.ts` و`src/lib/compression-service.ts` | الضغط والإصلاح والحماية |
| `src/lib/annotation-service.ts` و`src/lib/preview-service.ts` | العلامات والترقيم والقص والمعاينات |
| `src/lib/local-save.ts` | الحفظ المحلي والتنزيل |
| `scripts/copy-pdfjs-assets.mjs` | تجهيز الأصول المحلية للبناء |

المشروع مبني بـ React وTypeScript وVite، ويستخدم PDF.js وpdf-lib وqpdf WASM وJSZip. تفاصيل الإصدارات والحقوق في [THIRD_PARTY.md](THIRD_PARTY.md).
